Step by Step

How to Install MSTS Addons

The 4 steps that work for routes, locos, sounds and mods alike — each sub-page has its own detailed guide too.

  1. Download & Extract — Download the zip/rar archive and extract it with WinRAR or 7-Zip.
  2. Copy to the Right Folder — Routes go to ROUTES\, locos to TRAINS\TRAINSET\, sounds to SOUNDS\.
  3. Run installme.bat — If the pack ships installme.bat, run it to pull required default assets.
  4. Launch & Enjoy — Open MSTS or Open Rails, select the new content and start your session!
