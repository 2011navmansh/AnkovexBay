How to Install

  1. Download all 9 parts — keep every .rar file in a single folder.
  2. Extract Part 01 — right-click 478961498.part01.rar and choose Extract with WinRAR / 7-Zip.
  3. Copy to Routes — move the extracted route folder into .../Train Simulator/ROUTES/.
  4. Run installme.bat — if present, double-click it inside the route folder to pull required default assets.
  5. Add the activities — grab the ready-to-run TSDRV6 + TSDR V5 activity pack from the Activities page.
  6. Launch — open MSTS or Open Rails and select the route.
