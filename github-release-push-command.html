GitHub Release Push Command

Publish a release straight from an offline repo folder — enter a tag name, and the command uploads every file in the folder as release assets in one go.

code PowerShell upload_file gh CLI · release upload folder Works on offline repo folders verified Copy · Paste · Run

The Command

Copy the command below, paste it into a PowerShell window opened inside your repo folder, and press Enter. It asks for a tag name — numeric tags automatically get a v prefix, spaces become underscores — then creates the release and uploads every file in the folder.

arrow_back Back to Tips & PDFs
info

What it does, step by step: asks for the tag via Read-Host → trims it and swaps spaces for underscores → if the tag is pure digits, prefixes it with v → collects the full path of every file in the current folder → runs gh release create with all files as assets, titled Release <tag> with the note Automated release push.

How to Use

  1. Install the tools — you need the GitHub CLI (gh) installed and signed in once with gh auth login.
  2. Open the folder — put the files you want to upload into your offline repo folder (or any folder synced there), right-click the folder and choose Open in Terminal (PowerShell).
  3. Paste the command — right-click to paste in PowerShell, press Enter.
  4. Enter the tag — type your tag when asked (e.g. v54813 or hhgg5587) and press Enter.
  5. Done — the release is created with every file in the folder attached as an asset. Workspace files only: subfolders are not scanned, only files directly in the folder.
warning

Requires the folder to be inside a git repository with push rights (gh targets the repo of the current folder). Large releases may take a while to upload — let the terminal finish on its own.
