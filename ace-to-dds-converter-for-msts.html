Overview

ACE.to.DDS.converter.for.MSTS is a texture conversion tool for the MSTS community. Microsoft Train Simulator stores its textures in the legacy .ace format, while modern tooling (and Open Rails) increasingly prefers .dds. This converter batches entire folders of ACE textures and converts them to DDS in one run — no per-file fiddling.

The whole tool is packaged as a single .7z archive — extract it anywhere and run it. It is fully portable: no installer, no registry entries, nothing left behind.

Key Features

  • Batch ACE → DDS — point it at a folder of ACE textures and convert the whole set at once.
  • MSTS Ready — understands the ACE texture format used by MSTS routes and consists.
  • Open Rails Compatible — output DDS files load cleanly in Open Rails sessions.
  • Portable — single 7z archive, extract and run from any folder or USB stick.
info

Tip: keep a backup of your original .ace files before batch converting — you may want to roll a route back to the originals later.

System Requirements

  • Windows 10 or Windows 11 (64-bit)
  • 7-Zip, WinRAR or any archiver that reads 7z archives
  • MSTS installed and/or Open Rails
  • No further requirements — light, portable tool

Note: the converter only changes texture files — route files, consists and activities are untouched. Always convert a copy of a route's TEXTURES folder first if you want a safe rollback path.

How to Install

This tool is portable — there is nothing to install. Just extract and run.

  1. Download the Archive — grab ACE.to.DDS.converter.for.MSTS.7z via the button below.
  2. Extract — right-click the 7z file and extract it with 7-Zip or WinRAR to any folder.
  3. Backup First — copy the MSTS TEXTURES folder (or route folder) you plan to convert.
  4. Run & Convert — launch the converter, point it at the folder of ACE textures, and start the batch conversion.
  5. Verify — open the route or consist in MSTS / Open Rails and check the textures render correctly.
