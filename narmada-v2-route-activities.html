About These Activities

The Narmada V2 Route Activities pack collects four ready-to-run scenario files built for the Narmada V2 route in Microsoft Train Simulator and Open Rails. The set covers long-distance express runs across the Narmada valley mainline, from the busy approaches around Itarsi through Jabalpur and onward toward Katni and Satna.

Each activity is supplied as a single RAR archive. Download the scenario you want, extract it, and copy the activity files into the ACTIVITIES folder of your Narmada V2 route to start driving.

Included Activities

  • 11072 — Kamayani Express — 88 KB
  • 11077 — Jhelum Express — 71 KB
  • 12628 — Karnataka Express (PT) — 73 KB
  • 12943 — Udyogkarmi SF Express (PT) — 70 KB

What You Need

Install the Narmada V2 route first, along with the required track packs listed on the route page. Then load any of these activities in MSTS or Open Rails for a ready-made express run through Central India's Narmada valley corridor.

How to Load Narmada V2 Route Activities

Quick 4-step guide to get any Narmada activity running inside Microsoft Train Simulator or Open Rails.

  1. Download the Activity File — choose the activity you want in the table below and save the .rar file to your PC.
  2. Extract — right-click the RAR and extract with WinRAR or 7-Zip into a folder.
  3. Copy to the Route Folder — move the extracted activity files into the ACTIVITIES folder of your Narmada V2 route in .../Train Simulator/ROUTES/.
  4. Drive & Enjoy — open MSTS or Open Rails, select the activity and start your run along the Narmada valley.
