About This Backup

The MSTS Folder Backup / Preinstalled is a complete copy of a working Microsoft Train Simulator installation folder, preserved as a six-part 7z archive. Instead of installing MSTS and rebuilding your setup piece by piece, you extract the folder once and you are ready to run.

It is built for the situations every MSTS player eventually runs into: a fresh Windows install, a move to a new PC, a corrupted simulator folder, or the need to get back to a known-good setup without spending hours copying files and re-running installers.

The archive keeps the original directory structure intact. Routes, trains, sounds, global files, settings and other content that were part of the backed-up installation stay exactly where they belong, so MSTS and Open Rails can read the folder normally.

Why Use a Preinstalled Folder?

  • Fast recovery — restore a complete working simulator in the time it takes to extract an archive.
  • No setup marathon — skip the usual install, patch and folder-copy routine.
  • Great for upgrades — move your MSTS setup to a new drive or a new computer without rebuilding it.
  • Clean baseline — keep a known-good copy ready for testing addons or troubleshooting a broken install.
  • Simple to use — download all six parts, extract Part 001 with 7-Zip, and launch.
info

Note: this is a folder backup, not an installer. Back up or rename your existing MSTS folder before replacing anything, so you can always roll back.

What's Inside the Archive

The download contains the complete MSTS folder in a standard Train Simulator layout. Typical folders include:

  • ROUTES — installed routes, their tiles, activities, services and traffic files.
  • TRAINS — locomotives, coaches, wagons, cab views and consist files.
  • SOUND — locomotive, horn, brake and ambient sound files.
  • GLOBAL — shared track, road, signal and environment definitions.
  • GUI, ENV, UTILS and support files — the standard MSTS interface and utility content.

Because the folder is preserved as a backup, any routes, rolling stock, sounds and personal settings that were present in the original installation travel with it. Nothing needs to be assembled separately for the base folder.

How to Install the Folder Backup

A quick six-step guide to get the preinstalled MSTS folder running. The download is split into six 7z volumes (~11.3 GB total).

  1. Download All 6 Parts — save MSTS.7z.001 through MSTS.7z.006 into the same folder. Do not rename them.
  2. Install 7-Zip — use 7-Zip (or a recent WinRAR) so split 7z archives are handled correctly.
  3. Extract Part 001 — right-click MSTS.7z.001 → 7-Zip → Extract Here. The other five parts are picked up automatically.
  4. Choose the Location — move the extracted MSTS folder to a simple path such as C:\MSTS or D:\Train Simulator.
  5. Check Permissions — if files refuse to write, right-click the game executable and run it as administrator once.
  6. Launch & Play — open MSTS, or add the extracted folder as the content path in Open Rails, and start your session.
lightbulb

Tip: extract to a short path without special characters. Long folder names can cause problems with older MSTS utilities.
