Quick 4-Step Guide

How to Install Plugins & Extensions

Quick 4-step guide to install any AE/PR plugin safely on Windows.

01
download

Download & Extract

Download the plugin/archive and extract using WinRAR or 7-Zip if needed.

02
block

Close the App

Close After Effects / Premiere Pro and pause your anti-virus during install if asked.

03
folder_copy

Copy to Plug-ins Folder

Copy the plugin folder to ...Adobe After Effects\Support Files\Plug-ins or use the bundled installer.

04
restart_alt

Restart & Enjoy

Restart AE / PR, find the plugin under the Effects & Presets panel and start creating.
