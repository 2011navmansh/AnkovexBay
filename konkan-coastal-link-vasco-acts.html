About These Activities

This page collects 13 ready-to-run activity files for the Konkan Coastal Link — Vasco Update route for Microsoft Train Simulator (MSTS) and Open Rails. Each scenario is a separate ZIP / RAR archive with its own direct download link.

  • 07311 — VSG–MZP Special — coastal special from Vasco da Gama to Madgaon.
  • 10103 — Mandovi Express — the classic Mumbai–Madgaon Mandovi Express running along the Konkan coast.
  • 12133 — Rocket Express — ready-to-run 12133 Rocket Express activity.
  • 12283 — Duronto Express — non-stop Duronto run on the coastal link.
  • 12471 — Vasco–Patna Express — long-distance Vasco da Gama to Patna Express starting on the Konkan coast.
  • 12618 — Mangala Lakshadweep Express — crossing the coastal section.
  • 16345 — Garib Rath Express — ready-to-run Garib Rath activity.
  • Konkan Kanya & Goa Express — Double Duty — 20111 / 12449 Konkan Kanya and Goa double-duty pack.
  • 20645 — MAO–MAQ Vande Bharat Express — Vande Bharat run between Madgaon and Mangaluru on the coastal link.
  • 22629 — Dadar–Tirunelveli Express — leaving the coast at Panvel.
  • 50108 — by Anukalp — community-built activity.
  • Double Duty Act — VS Konkan — double-duty activity built for the refreshed Vasco Update.
  • The Energy Run — LPG on the Rails — LPG tankers on the coastal line, by Devanshu.

How to Load Konkan Coastal Link Activities

Quick 4-step guide to get any Konkan Coastal Link (Vasco Update) activity running inside Microsoft Train Simulator or Open Rails.

  1. Download the Activity File — use the Download button in the table above. Save the .zip / .rar file to your PC.
  2. Extract — right-click the archive and extract with WinRAR or 7-Zip into a folder.
  3. Copy to the Route Folder — move the extracted activity files into the ACTIVITIES folder of your Konkan Coastal Link route in .../Train Simulator/ROUTES/.
  4. Drive & Enjoy — open MSTS or Open Rails, select the activity and start your Konkan coastal run. Enjoy the session!
