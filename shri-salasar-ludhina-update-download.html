How to Install

  1. Download all 13 parts — keep every .rar file in a single folder.
  2. Extract Part 01 — right-click SHRI.SALASAR.LUDHINA.UPDATE.part01.rar and choose Extract with WinRAR / 7-Zip.
  3. Copy to Routes — move the extracted route folder into .../Train Simulator/ROUTES/.
  4. Run installme.bat — if present, double-click it inside the route folder to pull required default assets.
  5. Launch — open MSTS or Open Rails and select the route.
