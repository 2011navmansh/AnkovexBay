Editor's Tip Library

Every guide from the cards above, in full — follow the steps in order.

Best Export Settings

YouTube, Reels & Shorts — 2026 settings. The exact bitrate, resolution and codec settings that keep quality high and file size low.

  1. YouTube 1080p — H.264 · VBR 2-pass · Target 12 Mbps, max 20 Mbps · Audio AAC 320 kbps.
  2. YouTube 4K — H.264 · Target 45 Mbps, max 60 Mbps · Keyframe interval 2s · Render at maximum depth.
  3. Reels / Shorts — 1080×1920 · H.264 · 10–15 Mbps · Keep under 60s for full quality on Instagram.
  4. Always — Use Hardware encoding if GPU supports it, and match sequence settings to avoid scaling.

Motion Graphics Basics

Easing & timing with the graph editor — the graph editor is 80% of good motion design.

  1. Never leave linear keyframes — Linear motion looks robotic. Select keys and press F9 (easy ease) as your first habit.
  2. Use the graph editor — Speed graph, not value graph. Shape curves like an S — fast middle, soft start and end.
  3. Add overshoot — Let movement go slightly past the target and settle back. That bounce reads as premium.
  4. Anticipation sells action — A tiny move backwards before the main motion makes animations feel alive.

Clean Green Screen Keys

Keylight, despill & edge work — a believable composite with no green fringe, no halos and no clipped hair.

  1. Light the screen, not the subject — Even green = easy key. Fix lighting before blaming the plugin.
  2. Keylight: screen colour + screen matte — Pick the green, raise clip black until the background is pure, then clip white for solid subject.
  3. Kill the spill — Use Keylight Screen Despill or a hue shift on green range so edges lose the green fringe.
  4. Refine the matte — Shrink/soften the matte 0.5–1px and use Simple Choker for clean hair edges.

Audio Mixing Tricks

Essential Sound panel workflow — mix dialogue, music and SFX like a pro mixer without an external DAW.

  1. Tag your audio — Mark clips as Dialogue, Music or SFX in the Essential Sound panel — PR then gives you the right tools.
  2. Auto-duck music — Enable Ducking on music so it dips under dialogue automatically. -12dB, 200ms fade.
  3. Layer ambience — Room tone under every scene removes the "dead air" feeling. Keep it -30dB or lower.
  4. Loudness targets — Dialogue should sit around -6dB peaks. Export at -14 LUFS for YouTube.

Speed Ramps & Time Remapping

Velocity that looks intentional — smooth ramps, freeze frames and slow-mo done correctly.

  1. Enable time remapping — Right-click clip > Show Clip Keyframes > Time Remapping > Speed in PR.
  2. Split the ramp — Add speed keyframes, drag the middle section — the ramp handles ease automatically.
  3. Optical flow for slow-mo — Use Time Interpolation: Optical Flow for frame interpolation. Twixtor for extreme slow-mo.
  4. Freeze frame punch — Freeze at the peak action moment, add scale +1% over 5 frames, then release into the ramp.

Render & Preview Faster

Cache, proxies & GPU acceleration — make AE & PR feel instant even on mid-range PCs.

  1. Move media cache to SSD — Preferences > Media Cache > set to your fastest drive. Clear old cache monthly.
  2. Use proxies — Right-click footage > Proxy > Create Proxies. Edit smooth, export full quality.
  3. Drop playback resolution — Preview at 1/2 or 1/4 resolution. Final export is always full-res anyway.
  4. GPU acceleration ON — Set Mercury Playback Engine (GPU) in PR and enable Hardware-accelerated decode in AE.
Practice each step on a small project first — muscle memory beats theory.
