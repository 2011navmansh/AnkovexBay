About NS Sounds

NS Sounds is a raw sound-sample library for Microsoft Train Simulator & Open Rails. It collects 11 WAV files from the NS set — engine and traction loops for ALCO, EMD, WAG-9, WAG-12 and WAP-7 locomotives, plus a handful of horn takes for cab and AI sound edits.

Every file is listed in its own card below. Each card opens a separate download page holding the exact WAV link fetched from the NS release. Click Download there, wait for the 8-second MSTS Donation popup, and the file opens in a new tab. Nothing is locked behind a payment.

Library Highlights

  • 11 separate WAV files — no bundle, no archive to extract
  • ALCO and EMD prime-mover loops
  • WAG-9 and WAG-12 electric freight traction audio
  • WAP-7 horns and running sounds
  • Free downloads — every sound has its own page

Compatibility

  • Runs on Microsoft Train Simulator (MSTS) and Open Rails.
  • Windows — 32-bit or 64-bit.
  • Each file is a standalone WAV, so you can pick only the sounds you need.
  • Best used with standard .sms / .eng sound definitions.

How to Install

  1. Pick a file — find the horn or engine loop you need in the cards below.
  2. Open the download page — each card opens its own page; click Download there, wait for the MSTS Donation popup countdown, then close it to open the WAV.
  3. Back up — copy the sound you are replacing somewhere safe.
  4. Convert if needed — MSTS prefers 22 kHz mono WAV; convert with an audio editor if your file differs.
  5. Wire it in — point the .sms / .eng definition at the new WAV file and launch MSTS or Open Rails.
