Step by Step

How to Install EMU Packs

Easy step-by-step setup to install EMU rakes into Train Simulator & Open Rails.

  1. Extract the Archive — Extract the RAR / 7z file to get the EMU folder (containing .eng, .wag and .s files).
  2. Copy to TRAINSET — Place the extracted EMU folder into .../Train Simulator/TRAINS/TRAINSET/.
  3. Build a Consist — Use ConBuilder, Consist Editor or the Open Rails consist creator to couple the motor coaches and trailers.
  4. Run a Local — Pick your suburban route and run a full EMU stopper service.
