Quick 4-Step Guide

How to Install MSTS Reshades

Quick 4-step guide to apply any preset inside ReShade for Microsoft Train Simulator or Open Rails.

01
extension

Install ReShade First

Run the ReShade installer and point it at your train.exe (or OpenRails.exe) file.

02
download

Download & Extract

Download the preset zip/rar archive and extract it with WinRAR or 7-Zip.

03
content_copy

Copy the Preset File

Drop the .ini preset into the folder where ReShade was installed (next to the game exe).

04
sports_esports

Load & Enjoy

Launch MSTS / Open Rails, press Home to open the ReShade bar, pick the preset and start driving!
